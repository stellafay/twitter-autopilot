# 🚀 Twitter Autopilot Control Hub

歡迎來到推特全自動營運中樞。本倉庫專為 **Meta Muse AI** 與 **DSH AI 智囊團** 雙向協同設計。

---

## 📂 架構設計

- `config/`: 帳號 Persona 定位、System Prompt、回覆風格與風控邊界
- `queue/pending/`: 待發布推文隊列（含 Hook、正文、標籤、排程發布時間）
- `queue/published/`: 已發布推文存檔與互動數據反饋
- `assets/`: 推文配圖、視覺風格指南
- `monitoring/`: 監控的大V名單、截流關鍵字清單
